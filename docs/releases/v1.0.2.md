# OpenCommander 1.0.2 — versi komponen disamakan

Agent Windows, installer, gateway, server MCP, paket plugin, plugin terhubung, metadata updater, dan paket infrastruktur memakai nomor versi 1.0.2. Rilis ini menyamakan penomoran yang sebelumnya berbeda antara agent/server 0.5.1 dan plugin terhubung 1.0.1.

Pemeriksaan versi dijalankan sebelum build, pengemasan, dan penandatanganan metadata updater. Proses berhenti jika manifest komponen tidak cocok dengan file `VERSION`.

Pembersihan riwayat tetap berjalan setelah satu jam tanpa penggunaan MCP ketika tidak ada tugas aktif. Teks diagnostik Windows sekarang mengikuti aturan satu jam. Pairing, izin, dan file kerja dipertahankan. Motion Graphics dan DirectorStudio tetap tersedia.

## Unduhan

- `OpenCommanderSetup.exe` — installer Windows x64 1.0.2; gunakan `--upgrade` untuk memperbarui instalasi yang sudah ada.
- `opencommander-agent.exe` — agent Windows Rust 1.0.2.
- `OpenCommander-Windows-1.0.2.zip` — installer, agent, panduan, dan lisensi dependency.
- `OpenCommander-plugin-1.0.2.zip` — manifest dan skill Windows/WordCraft.
- `wordcraft-0.7.0-windows-x64-portable.zip` — WordCraft upstream, tetap versi 0.7.0 karena merupakan produk terpisah.
- `OpenCommander_Logo_GIF_Pack.zip` — gambar dan ikon proyek.
- `SHA256SUMS.txt` — SHA-256 seluruh aset rilis.

Binary Windows belum ditandatangani Authenticode. Metadata updater menggunakan Ed25519. Catatan rilis lama dipertahankan sebagai riwayat.
