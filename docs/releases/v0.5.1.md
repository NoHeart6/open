# OpenCommander 0.5.1 — pembersihan riwayat setelah satu jam tidak aktif

Riwayat tugas, hasil, keluaran terminal, dan log aktivitas sekarang otomatis dihapus setelah satu jam tanpa penggunaan MCP, ketika tidak ada tugas aktif. Perubahan diterapkan pada agent Windows dan gateway; petunjuk plugin dan deskripsi tool MCP mengikuti aturan yang sama.

- Pemanggilan tool, pembacaan status/output, dan eksekusi tugas memperbarui waktu aktivitas. Heartbeat dan pengiriman ulang hasil yang sudah dicatat tidak memperpanjangnya.
- Pembersihan saat startup berjalan sebelum pemulihan tugas, sehingga jurnal lama yang memenuhi batas 64 MiB dapat dibersihkan tanpa menggagalkan startup.
- Pairing, pengaturan izin, file kerja, trash, dan receipt undo dipertahankan. Riwayat yang sudah dihapus tidak dapat dibaca kembali; periksa keadaan aktual sebelum mengulangi tindakan lama.
- Fitur Motion Graphics, termasuk komposisi DirectorStudio yang sudah ada di source terbaru, tetap tersedia.

## Verifikasi

Pengujian agent Windows: 39 lulus, 3 pengujian opsional dilewati. Pengujian gateway, Go vet, pemeriksaan Rust Clippy, serta lint/typecheck dan pengujian MCP lulus. Batas satu jam diuji dengan waktu terkontrol; bukan dengan menunggu satu jam pada akun pengguna. Panggilan MCP `system_info` berhasil pada agent 0.5.1 yang terpasang. MCP dan gateway Railway melaporkan versi 0.5.1, dengan `history_idle_seconds: 3600` pada gateway.

Binary Windows belum ditandatangani Authenticode. Metadata updater menggunakan Ed25519; cocokkan unduhan dengan `SHA256SUMS.txt`.
