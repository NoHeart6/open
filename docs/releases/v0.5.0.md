# OpenCommander 0.5.0 — Windows, WordCraft, dan plugin MCP

Agent Windows native Rust yang menghubungkan pekerjaan file, terminal, desktop, dan WordCraft ke percakapan melalui MCP. Rilis ini menambahkan distribusi unduhan GitHub untuk build 0.5.0 yang sudah ada, paket plugin, dan WordCraft portable.

## Kemampuan 0.5.0

- 42 tools MCP, termasuk `file_export`, `workflow`, `wordcraft_compose`, dan `visual_agent`.
- Ekspor file biner hingga 512 MiB melalui chunk, workflow hingga 20 langkah dengan checkpoint, serta pemeriksaan hasil tiap langkah.
- Penyusunan DOCX native melalui WordCraft: judul, heading, paragraf, gambar, caption, tabel, dan page break; maksimal 80 blok.
- Terminal paralel, stdin interaktif, dan ConPTY untuk aplikasi terminal.
- OAuth, pairing perangkat, kebijakan folder/aplikasi, dan konfirmasi native sesuai pengaturan pemilik.

## Memulai

1. Jalankan installer. Untuk upgrade, gunakan `OpenCommanderSetup.exe --upgrade` agar pairing dan izin yang tersimpan dipertahankan.
2. Hubungkan MCP `https://mcp-production-394c.up.railway.app/mcp` dengan OAuth pada host yang mendukungnya. Verifikasi `device_list` dan `system_info`.
3. Ekstrak WordCraft portable, jalankan `wordcraft.exe --control 7981`, dan izinkan executable/CLI serta folder dokumen melalui OpenCommander.
4. Gunakan `wordcraft` dengan `cli_path` absolut ke `wordcraft-cli.exe`; mulai dengan `list_commands`.

## Asal binary dan verifikasi distribusi

Binary OpenCommander diterbitkan dari paket lokal 0.5.0 yang sudah tersedia, tanpa membangun ulang atau mengubah implementasi. `opencommander-agent.exe --version` menghasilkan `opencommander-agent 0.5.0`. Hash agent di ZIP sama dengan EXE terpisah dan installer: `77d2398444d54f2121e48a2e00d346f80a0651e766465fececc86e497fa8f764`. Paket Windows diperiksa CRC dan daftar isinya.

WordCraft portable diterbitkan ulang tanpa modifikasi. SHA-256-nya cocok dengan digest aset pada [rilis upstream 0.7.0](https://github.com/storytold/wordcraft/releases/tag/v0.7.0), yang diperiksa langsung melalui API GitHub: `e6c8be9bb8ff815ed96974b8a25773d1e476301dcd5b242a267b88347185cc4f`. WordCraft berasal dari [storytold/wordcraft](https://github.com/storytold/wordcraft) dan mempertahankan lisensi MIT OR Apache-2.0 serta pemberitahuan font dalam ZIP.

Untuk memeriksa unduhan Windows:

```powershell
Get-FileHash .\OpenCommanderSetup.exe -Algorithm SHA256
Get-FileHash .\wordcraft-0.7.0-windows-x64-portable.zip -Algorithm SHA256
```

Bandingkan dengan `SHA256SUMS.txt` pada rilis yang sama. EXE **belum ditandatangani Authenticode**. Metadata updater bertanda tangan Ed25519 adalah mekanisme terpisah dari checksum unduhan GitHub.

## Batas yang perlu diketahui

- Akses MCP kustom mengikuti kemampuan akun/host ChatGPT. ZIP plugin tidak otomatis memasang koneksi pada akun.
- Pengujian klien MCP atau kesehatan endpoint tidak membuktikan penerimaan end-to-end pada percakapan ChatGPT pengguna.
- Transfer file yang dihasilkan ChatGPT bergantung pada bytes/URL unduhan yang diberikan host; path internal `sandbox:/...` saja tidak cukup.
- Ekspor chunk bukan mekanisme lampiran/upload otomatis ke host ChatGPT. Penalaran AI tetap di ChatGPT; rilis ini tidak memasang model bahasa lokal.
